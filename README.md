# Simple Portfolio

A clean, single-page personal portfolio website — hand-built with plain HTML, Tailwind CSS (via CDN), and Lucide icons. Dark, modern design with animated background pattern, glassmorphism cards, and gradient typography.

## Features

- Single-file responsive portfolio site (`index.html`)
- Dark theme with animated SVG background grid
- Glassmorphism-style cards and sections
- Smooth-scroll navigation
- Google Fonts (Inter + Tiro Devanagari Hindi) and Lucide icons via CDN

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Lucide icons (CDN)

## Quick Start

No build step required — just open the file in a browser:

```bash
# Clone the repo
git clone https://github.com/girishlade111/simple-portfolio.git
cd simple-portfolio

# Open in your browser
# on Linux:
xdg-open index.html
# on macOS:
open index.html
# on Windows: double-click index.html
```
